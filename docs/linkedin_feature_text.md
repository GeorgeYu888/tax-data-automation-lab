## Title

Enterprise Tax Data Automation Lab - Python, SQL, Review Queues and Reconciliation

## Short Description

I built a practical enterprise tax data automation portfolio project using synthetic finance data for a fictional listed-group style company. The workflow applies configurable tax classification rules, validates data quality, reconciles expected outputs, flags exceptions for human review and writes audit-friendly outputs to CSV and DuckDB.

The dataset covers domestic GST/BAS, export sales, imported goods/services, intercompany recharges, transfer-pricing review, withholding-tax review, FBT evidence review, R&D expenditure review, trust/fund distributions, consolidation eliminations, capital purchases, tax provision journals and treasury/hedging records.

This is part of my transition into data automation and AI-enabled business transformation. It demonstrates Python, SQL, rules-based processing, reference data mapping, testing and documentation while staying clear that I am not presenting myself as a tax adviser or production tax engineer.
